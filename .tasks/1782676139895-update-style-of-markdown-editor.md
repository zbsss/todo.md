I don't like the typography and style of the markdown editor. 
- The background of the text editor is white and stands out.
- The font is too skinny, pick something nicer and more fun.
- Code blocks "```" have really bad contrast and are not readable (dark blue text on black background).
- When editing Title, the background changes to a white strip. If the title is long part of it will become hidden (when in editing mode).
